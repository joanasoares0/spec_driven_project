# Developer Quickstart: Pokémon TCG 151 Booster Pack Opener

**Branch**: `001-pokemon-tcg-booster`

---

## Prerequisites

| Tool | Minimum version | Check |
|------|----------------|-------|
| Python | 3.10 | `python --version` |
| pip | bundled with Python | `pip --version` |
| Node.js | 18 LTS | `node --version` |
| npm | 9 | `npm --version` |

---

## Step 1 — Install Python dependencies

```bash
pip install requests
```

---

## Step 2 — Download card assets

```bash
python download_cards.py
```

This will:
1. Fetch all Pokémon 151 (sv3pt5) cards from pokemontcg.io.
2. Create `assets/01_comum/` through `assets/07_legendária/` and download each card image.
3. Write `assets/data/cards.json` (the card manifest the app loads at startup).

Expected output: ~165 `.jpg` files across 7 folders, plus `cards.json`.

**Optional — API key** (raises rate limit from 1,000 to 20,000 req/day):
```bash
POKEMONTCG_API_KEY=your_key_here python download_cards.py
```

**Re-running**: Safe to run again — existing files are skipped.

---

## Step 3 — Install JavaScript dependencies

```bash
npm install
```

---

## Step 4 — Start development server

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## Step 5 — Run tests

```bash
npm test
```

Runs the Vitest suite including:
- `tests/rng.test.js` — RNG determinism and uniformity.
- `tests/pack.test.js` — Slot distribution over 10,000 seeded packs (seed `42`).
- `tests/collection.test.js` — localStorage read/write and filter logic.

---

## Step 6 — Build for production

```bash
npm run build
```

Output goes to `dist/`. Deploy the `dist/` directory to any static host (GitHub Pages,
Netlify, Vercel, Cloudflare Pages, etc.). No server required.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: requests` | Run `pip install requests` |
| `404 on assets/data/cards.json` | Run `python download_cards.py` first |
| Images not displaying | Verify `assets/` folders exist and contain `.jpg` files |
| `localStorage` quota warning | Open browser in a non-private window with storage enabled |
| Vitest distribution test fails | Check that `assets/data/cards.json` exists and pools are populated |
