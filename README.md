# Pokémon TCG 151 — Booster Pack Opener

A browser-based simulator for opening booster packs from the **Scarlet & Violet — 151 (sv3pt5)** set. Open packs, reveal cards one at a time, and build your complete 165-card collection.

![stack](https://img.shields.io/badge/Vite-5-646CFF?logo=vite&logoColor=white) ![js](https://img.shields.io/badge/JavaScript-ES2022-F7DF1E?logo=javascript&logoColor=black) ![tests](https://img.shields.io/badge/Vitest-passing-6E9F18?logo=vitest&logoColor=white)

---

## Features

- **Hand layout** — 6 cards fanned out below; the active card rises to the top in a large stage
- **3D flip animation** — click reveals the card; click again to advance to the next
- **Navigation** — ‹ › buttons or `←` `→` / `Space` keys to move through the hand
- **Accurate pull rates** — slots 1–4 always Common, slot 5 (90% Uncommon / 10% Rare), slot 6 (60/25/10/4.5/0.5 distribution)
- **Persistent collection** — saved to `localStorage`; dedicated tab with 165 card slots, silhouettes for unowned cards and copy count badges
- **Rarity filters** — filter the collection by tier
- **Offline-capable** — zero backend; runs entirely in the browser after the initial asset download

---

## Requirements

- Node.js 18+
- Python 3.10+ (only needed for the asset download script)
- [pokemontcg.io](https://pokemontcg.io) API key (free tier)

---

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Download card images (~165 JPG files)
POKEMONTCG_API_KEY=<your-key> python download_cards.py

# 3. Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.

## Project Structure

```
assets/
  01_comum/               # card images organised by rarity (generated by script)
  02_incomum/
  03_raras/
  04_duplo_raras/
  05_arte_secreta/
  06_duplo_arte_secreta/
  07_legendária/
  data/cards.json         # card manifest generated by the script
src/
  main.js                 # bootstrap and tab navigation
  modules/
    pack.js               # pack draw logic (slot distribution rules)
    rng.js                # deterministic mulberry32 RNG
    collection.js         # localStorage persistence
    ui/
      packView.js         # pack opening UI (stage + hand)
      collectionView.js   # collection grid UI
  styles/main.css
tests/                    # Vitest unit tests (distribution, RNG, collection)
```
